# Complétion — densifier le cerveau

Une fois le squelette en place, ces questions remplissent le cerveau avec du vrai contenu. Pose-les une à la fois, crée la note correspondante au fil des réponses. But : que la personne reparte avec un cerveau déjà utile, pas un dossier vide.

## Projets actifs

Pour chaque projet cité à l'intake :
- **Quel est le résultat visé, et la prochaine action concrète ?**
  → Crée une note dans `01-Projects/` à partir de `_templates/project.md`.

## Domaines de responsabilité

Pour chaque domaine cité :
- **Quel standard veux-tu tenir dans ce domaine ?**
  → Crée une note dans `02-Areas/` à partir de `_templates/area.md`.

## Première décision

- **Quelle décision importante as-tu prise récemment, et pourquoi ?**
  → Ajoute-la au `Decisions/decision-log.md`. Ça amorce ta mémoire décisionnelle.

## Premières ressources

- **Quels 2-3 sujets reviens-tu souvent consulter ?** (livres, références, méthodes)
  → Crée des notes dans `03-Resources/`.

## Premier MOC (optionnel)

- **Y a-t-il déjà un sujet qui touche plusieurs de tes notes ?** (ex. un client, un thème)
  → Si oui, crée un MOC dans `MOCs/` à partir de `_templates/moc.md` et relie les notes concernées. Sinon, laisse venir — un MOC émerge quand 5+ notes se rejoignent.

## Clôture

Montre à la personne le geste quotidien :
1. Ouvrir une daily note pour capturer.
2. Laisser l'assistant relier et classer.
3. Revenir au vault en fenêtre de réflexion, pas pour chercher — pour penser.

Rappelle : commence petit, garde-le vivant. Un cerveau qui sert chaque jour bat un système parfait jamais ouvert.
