# Régler ton assistant (5 minutes)

Ton cerveau garde le contexte. Les réglages ci-dessous font que ton assistant te reconnaît partout, même hors du dossier.

## 1. Tes instructions personnelles

Elles s'appliquent à **toutes** tes conversations : reste court et général, le détail vit dans ton cerveau.

| App | Où |
|---|---|
| **Claude** | Tes initiales en bas à gauche → **Settings** → **General** → **Instructions for Claude** (« Instructions pour Claude ») |
| **ChatGPT** | **Settings** → **Personalization** → **Enable customization** → **Custom Instructions** |

Copie ce texte, remplace les crochets :

```text
Je suis [prénom nom], [métier] ([entreprise, ville]).
Style : français clair, réponses courtes et structurées, termes techniques expliqués. Pour une décision : le problème, les options, ta recommandation.
Mon second cerveau est le dossier « second-brain ». Quand une conversation y a accès, ses fichiers (CLAUDE.md ou AGENTS.md, puis index.md) priment sur ces instructions. Sans accès, ne prétends pas l'avoir lu.
N'invente jamais un fait : écris « à confirmer ». Ne me demande jamais de mot de passe.
```

## 2. Les réglages de base

| App | Réglage | Valeur |
|---|---|---|
| Claude | Settings → **Memory** → **Generate memory from chats** | Activé |
| Claude | Settings → **Memory** → **Search and reference chats** | Activé (forfaits payants) |
| Claude | Settings → **Capabilities** → **Code execution and file creation** | Activé |
| ChatGPT | Settings → Personalization → **Memory** → **Reference saved memories** et **Reference chat history** | Activés |

Bon à savoir : quand ton assistant travaille dans ton dossier, c'est ton cerveau qui sert de mémoire, pas la mémoire de l'app. C'est voulu : tes notes restent chez toi et tu les vois dans Obsidian.

Les menus changent souvent : si un libellé diffère, cherche l'option la plus proche.
