# Checklist — à faire de ton côté

Pendant que l'assistant monte le squelette, voici les gestes manuels à faire toi-même. Coche au fur et à mesure.

## 1. Installer Obsidian

- [ ] Télécharge Obsidian (gratuit) : https://obsidian.md
- [ ] Installe-le et ouvre-le.

> Obsidian est l'app qui transforme un dossier de fichiers texte en cerveau navigable. Tout reste sur ta machine — aucun cloud, aucun compte obligatoire.

## 2. Créer le dossier du vault

- [ ] Crée un dossier sur ta machine pour ton cerveau (ex. `Documents/Mon-Cerveau`).
- [ ] C'est le chemin que tu donnes à l'assistant pour qu'il scaffold dedans.

## 3. Ouvrir le dossier comme vault dans Obsidian

- [ ] Dans Obsidian : « Open folder as vault » → choisis ton dossier.
- [ ] Tu vois maintenant la structure (Projects, Areas, MOCs, etc.) dans le panneau de gauche.

## 3 bis. Activer les modèles (2 minutes, une seule fois)

- [ ] Obsidian → **Paramètres** (roue dentée en bas à gauche) → **Modules principaux** (*Core plugins*).
- [ ] Active **Modèles** (*Templates*) → dans ses options, dossier des modèles : `_templates`.
- [ ] Active **Notes quotidiennes** (*Daily notes*) → dossier : `Daily-Notes` · modèle : `_templates/daily`.
- [ ] Teste : clique l'icône calendrier dans la barre de gauche → une note du jour s'ouvre, déjà datée.

## 4. Classer tes documents existants

- [ ] Rassemble ce que tu as déjà : notes, PDF, exports Google Docs.
- [ ] Range chaque chose dans le bon tiroir PARA :
  - Lié à un effort actif avec une fin → **01-Projects**
  - Responsabilité continue → **02-Areas**
  - Référence utile un jour → **03-Resources**
- [ ] Dans le doute, mets dans **03-Resources**. Tu déplaceras plus tard. Ne bloque pas là-dessus.

## 5. Vérifier que ton assistant est branché

- [ ] Ferme Claude, puis rouvre-le **dans le dossier de ton vault** (c'est là qu'il trouve `CLAUDE.md`, le fichier qui le branche sur ton cerveau).
- [ ] Demande : « Résume ce que tu sais sur moi et mon cerveau. »
- [ ] S'il répond avec ton rôle, tes domaines et tes projets, c'est branché. Sinon, vérifie que `CLAUDE.md` est bien à la racine du vault.

## 6. Premier usage

- [ ] Crée ta première daily note (icône calendrier dans Obsidian, ou demande à Claude « ouvre ma note du jour »).
- [ ] Note une idée, une tâche, une décision du jour.
- [ ] Demande à ton assistant de la relier à un projet ou un domaine existant.

Ton cerveau est vivant. À partir d'ici, il grandit avec toi.
