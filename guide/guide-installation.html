Important : il faut l'app de bureau installée sur ton ordinateur. Le site web (claude.ai ou chatgpt.com dans le navigateur) ne peut pas créer de fichiers sur ton ordinateur.
Où vivent tes notes ? Dans un simple dossier sur ton ordinateur. Pas de compte Obsidian, pas de cloud. Quand tu poses une question à ton assistant, il lit les notes nécessaires pour te répondre.

Étapes communes

1 Installer Obsidian 5 MIN

  1. Va sur obsidian.md → bouton Download.
  2. Installe-le comme n'importe quelle app (Mac : glisse Obsidian dans Applications · Windows : suis l'installateur).
  3. Ouvre-le une fois pour vérifier qu'il démarre. Pas besoin de compte. Tu peux le refermer.

2 Créer le dossier de ton cerveau 1 MIN

Crée un dossier vide nommé second-brain, là où tu ranges tes documents :

  • Mac : Documents/second-brain
  • Windows : Documents\second-brain

C'est ce dossier qui va contenir ton cerveau. Retiens où il est. Ensuite, suis un seul des deux parcours.

Parcours A Avec Claude

A1 Prendre l'abonnement Claude Pro 5 MIN

  1. Va sur claude.ai et crée un compte (ou connecte-toi).
  2. Passe au plan Pro (menu de ton profil → Upgrade / Mettre à niveau). Déjà Pro, Max ou Team ? Passe à A2.

A2 Installer l'app Claude 5 MIN

  1. Va sur claude.ai/download et télécharge la version Mac ou Windows.
  2. Installe-la, ouvre-la, connecte-toi.

A3 Ouvrir Claude dans ton dossier 2 MIN

  1. Dans l'app Claude, clique sur l'onglet Code (en haut).
  2. Choisis ton dossier second-brain comme dossier de travail.
Pourquoi l'onglet Code ? C'est le mode où Claude a le droit de créer des fichiers dans ton dossier. Aucun code à écrire — tu lui parles en français.

A4 Installer le Second Brain Starter 2 MIN

Dans la zone de texte, tape cette ligne puis Entrée :

/plugin marketplace add D4rthur/second-brain-starter

Puis celle-ci, et Entrée :

/plugin install second-brain-starter@arkytechs

Si Claude demande une confirmation, accepte. S'il propose de redémarrer la session, fais-le.

A5 Monter ton cerveau 15–20 MIN

Écris simplement :

Monte mon second cerveau

Puis passe à l'étape finale.

Parcours B Avec ChatGPT (Codex)

B1 Installer l'app Codex 5 MIN

  1. Va sur learn.chatgpt.com/docs/app et télécharge l'app pour Mac ou Windows.
  2. Installe-la, ouvre-la, connecte-toi avec ton compte ChatGPT.
Codex, c'est la version « code » de ChatGPT : le même compte, mais une app qui a le droit de créer des fichiers sur ton ordinateur. Aucun code à écrire — tu lui parles en français.

B2 Télécharger le Second Brain Starter 2 MIN

  1. Va sur github.com/D4rthur/second-brain-starter.
  2. Clique le bouton vert Code → Download ZIP.
  3. Décompresse le fichier (Mac : double-clic · Windows : clic droit → Extraire tout).
  4. Tu obtiens un dossier second-brain-starter-main. Laisse-le dans Téléchargements — pas dans second-brain.

B3 Ouvrir Codex dans ce dossier 2 MIN

  1. Dans l'app Codex, choisis Ouvrir un dossier (Open folder).
  2. Sélectionne le dossier second-brain-starter-main.
Pourquoi ce dossier-là ? Il contient le mode d'emploi (le fichier AGENTS.md) que Codex lit tout seul pour savoir comment monter ton cerveau.

B4 Monter ton cerveau 15–20 MIN

Écris (adapte le chemin si ton dossier est ailleurs) :

Monte mon second cerveau dans Documents/second-brain

Codex va te demander la permission d'écrire dans second-brain, puisque ce dossier est en dehors de celui que tu as ouvert : accepte.

Sécurité : garde le mode « Demander l'approbation » (Ask for approval), celui par défaut. N'active jamais « Accès complet » (Full access). Accepte seulement les demandes que tu comprends.

Pendant la construction

Ton assistant te pose 9 questions, une à la fois : ton nom, ton métier, tes domaines, tes projets… Réponds naturellement, comme à quelqu'un qui t'aide. Il construit ensuite ton cerveau dans second-brain, puis te pose quelques questions de plus pour le remplir. S'il demande la permission de créer des fichiers, accepte : c'est ton cerveau qui se construit.

✓ Étape finale — Ouvrir ton cerveau dans Obsidian 5 MIN

  1. Ouvre Obsidian → Ouvrir un dossier comme coffre (Open folder as vault) → choisis second-brain.
  2. Tes dossiers apparaissent à gauche : Projects, Areas, Resources…
  3. Active les modèles (une seule fois) : Paramètres (roue dentée en bas à gauche) → Modules principaux (Core plugins) :
    • Modèles (Templates) → dossier des modèles : _templates
    • Notes quotidiennes (Daily notes) → dossier : Daily-Notes · modèle : _templates/daily

✓ Vérifier que tout est branché 1 MIN

  1. Ferme ton assistant, puis rouvre-le directement dans le dossier second-brain (Claude : onglet Code → second-brain · Codex : Ouvrir un dossier → second-brain).
  2. Demande : « Résume ce que tu sais sur moi et mon cerveau. »
  3. S'il te parle de ton rôle, de tes domaines et de tes projets → c'est gagné.

Parcours B : le dossier second-brain-starter-main ne sert plus, tu peux le supprimer.

Au quotidien

  • Capturer : dis à ton assistant « note que… » ou « ajoute à ma note du jour… ». Il range au bon endroit.
  • Retrouver : « Qu'est-ce que j'avais décidé pour… ? » — il cherche dans ton cerveau.
  • Réfléchir : ouvre Obsidian et navigue dans tes notes.
Règle d'or : ouvre toujours ton assistant dans le dossier second-brain. Deux petits fichiers à sa racine, CLAUDE.md et AGENTS.md, lui rappellent qui tu es à chaque session. Ne les supprime pas.
